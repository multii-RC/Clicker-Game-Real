# P2-Clicker-Game

Made by Ryan Carney

Artistic statement
	I made a squirrel hunter clicker game where I want the plaer to feel the intensity and isolation of hunting.
	
	Assets:
		dead squirrel to replace the coin animation, could be other animals in the future. maybe bigger game for more expensive genreators.
		some kind of trap for the generators. I used a bear trap image, but they could scale as well with maybe a snare for the cheapest one.
		bow for clicker. To represent your hunting outside of trapping.
		try to find a sound for the squirrel or animal so it seems more immersive.
		A forest background for a hunting environment
		If I was to expand I would also add bgm or forest sounds with no music to simulate the isolation.
